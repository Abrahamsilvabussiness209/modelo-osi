Modelo OSI Interactivo

Haz clic en cualquier capa para explorar sus detalles, protocolos y dispositivos.

Capa 1

Física

▼

Transmisión de bits crudos (0s y 1s) a través del medion físico (voltaje, impulsos de luz o ondas de radio).

Cables UTP / Fibra Óptica Hubs Repetidores
Capa 2

Enlace de Datos

▼

Transfiere tramas de datos entre nodos en la misma red local. Maneja el direccionamiento físico (MAC).

Ethernet Wi-Fi (802.11) Direcciones MAC Switches
Capa 3

Red

▼

Determina la mejor ruta lógica (direccionamiento IP y enrutamiento) para enviar paquetes entre redes distintas.

IPv4 / IPv6 ICMP (Ping) Routers
Capa 4

Transporte

▼

Garantiza la transferencia confiable o rápida de datos entre hosts. Define el control de flujo y la corrección de errores.

TCP UDP Puertos (80, 443, etc.)
Capa 5

Sesión

▼

Establece, gestiona y finaliza las conexiones (sesiones) entre las aplicaciones en ambos extremos.

NetBIOS PPTP RPC
Capa 6

Presentación

▼

Se encarga del formato, cifrado y compresión de los datos para que sean interpretables por la capa de aplicación.

SSL / TLS JPEG / PNG ASCII
Capa 7

Aplicación

▼

Interfaz directa con las aplicaciones del usuario final. Proporciona servicios de red a las aplicaciones de software.

HTTP / HTTPS FTP DNS SMTP
Capa 8 Curiosidad / No Oficial

La Capa del Usuario (O Capa Política)

▼

🤖 ¿Sabías que...? En la cultura informática, la "Capa 8" se refiere sarcásticamente al ser humano que opera el equipo o a las políticas de la organización.


Se estima en broma que más del 80% de las fallas críticas de red catalogadas como "misteriosas" corresponden a errores de Capa 8, conocidos comúnmente como códigos de error PEBCAK (Problem Exists Between Chair And Keyboard) o Error ID-10-T.
